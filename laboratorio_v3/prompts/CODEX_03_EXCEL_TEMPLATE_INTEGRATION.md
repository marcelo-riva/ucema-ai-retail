# CODEX PROMPT 03 — Excel template integration

Hay un archivo template en:

`public/templates/NEXUS_RETAIL_LAB01_EJ01_PORTFOLIO_PACK_FINAL.xlsx`

Integrarlo en la pantalla del ejercicio.

## Requisitos

- El botón descargar debe apuntar a `/templates/NEXUS_RETAIL_LAB01_EJ01_PORTFOLIO_PACK_FINAL.xlsx`.
- Mostrar nombre del archivo.
- Mostrar descripción del contenido:
  - Caso de negocio
  - Base histórica de SKUs
  - Diccionario
  - Guía de exploración
  - Hipótesis del equipo
  - Decisiones SKU
  - Scoreboard alumno
  - Plan 90 días
  - Proyección 90 días con BASELINE_* y PROJECTED_*
- Mostrar aviso:
  "M01-M12 son históricos. M13-M15 son los próximos 90 días. BASELINE_* es referencia; PROJECTED_* es la proyección del equipo."
