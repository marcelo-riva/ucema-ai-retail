# CODEX PROMPT 03 — Workbook integration

Hay un workbook único en:

`public/templates/NEXUS_RETAIL_LAB01_WORKBOOK_COMPLETO.xlsx`

Integrarlo en todo el Laboratorio 1.

## Requisitos

- El botón descargar debe apuntar a `/templates/NEXUS_RETAIL_LAB01_WORKBOOK_COMPLETO.xlsx`.
- Mostrar nombre del archivo.
- Mostrar descripción del contenido:
  - Caso de negocio
  - Base histórica de SKUs
  - Diccionario
  - Guía de exploración
  - Diagnóstico inicial
  - Decisiones Portfolio
  - Decisiones Pricing
  - Forecast 90 días
  - Decisiones Inventory
  - Scoreboard alumno
  - Plan 90 días
  - Output final
  - Control de estado
- Mostrar aviso:
  "Este es el archivo de trabajo para todo el laboratorio. Si la plataforma falla, continuá desde el Excel con tu AI personal."

## Bonus

Agregar una sección "Subir checkpoint del workbook" con:
- Workbook actualizado obligatorio para enviar checkpoint.
- Reporte AI opcional.
