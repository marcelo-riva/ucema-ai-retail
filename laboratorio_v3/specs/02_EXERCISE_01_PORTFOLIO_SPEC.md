# Exercise 01 — Portfolio Optimization

## Objetivo

Definir una optimización de portfolio para 90 días.

El foco del ejercicio es clasificar SKUs como CORE, REVIEW o ELIMINAR y justificar
la decisión con datos. La proyección de 90 días aparece como preview de impacto; no
es obligatoria en Portfolio salvo indicación docente.

El alumno debe identificar:
- SKUs CORE.
- SKUs REVIEW.
- SKUs a ELIMINAR.
- Acciones de 90 días.
- Impacto esperado en capital, revenue y margen.

## Experiencia

1. El alumno entra al ejercicio.
2. Descarga pack Excel.
3. Usa su AI personal.
4. Completa diagnóstico, criterios y riesgos.
5. Completa decisiones por SKU.
6. Completa scoreboard propio.
7. Revisa preview de impacto.
8. Carga reporte AI opcional.
9. Envía entrega.
10. Plataforma valida estructura.
11. Plataforma genera `state_v1`.

## Input

- Base SKUs.
- Diccionario.
- Caso de negocio.
- Guía de exploración.
- Hipótesis del equipo.
- Template decisiones SKU.
- Scoreboard alumno.
- Plan 90 días opcional / recomendado.
- Proyección 90 días como preview.

## Output esperado del alumno

- Recomendación ejecutiva.
- Excel completado.
- Reporte AI opcional.
- Scoreboard alumno.
- Plan 90 días opcional / recomendado.
- Hoja `07_FORECAST_90_DIAS` opcional como preview en Portfolio.

## Output del sistema

- Submission registrada.
- Validación.
- Scoreboard sistema actualizado.
- Estado v1 simulado en Fase 0.
