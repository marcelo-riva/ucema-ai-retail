# Planificador base

Guardar aca el Excel original que funciona como referencia del simulador/planificador.

Este archivo sirve para:

- identificar variables de negocio;
- relevar formulas y supuestos;
- definir escenarios iniciales;
- contrastar el comportamiento del simulador nuevo contra el planificador original.

Nombre sugerido:

```text
planificador-base.xlsx
```

Si el archivo contiene datos sensibles o reales, crear una version anonimizada antes de commitearlo.
